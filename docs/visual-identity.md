# Identidad y experiencia

Base: brief, kickoff y SVG oficial. La corrección del usuario del 15 noviembre exige priorizar función y recuperar protagonismo del logo con composición móvil cuidada.

Crema `#FDEDD9`, vino `#4F0808`, Cloud Dancer `#F0EEE9`. Rose gold del isotipo; no inventar gradiente ni deformar SVG. Símbolo en header, portada y footer con nombre accesible; favicon oficial. Tipografías definitivas pendientes.

CSS Modules y tokens compartidos, globales limitados a base/reset. Texto alineado a la izquierda, longitud de lectura moderada, columnas que se apilan, nombres largos sin desbordar. Probar 320px, zoom 200%, teclado, foco visible y reduced motion.

BASIC/DEPT e Instrument inspiran criterio editorial, no activos para copiar. Evitar tarjetas repetidas, cristal y movimiento que distraigan. Método y fotos reales aportan identidad. No depender de hover, color o animación para comunicar una acción/error. Reservar dimensiones y mantener proporciones.
