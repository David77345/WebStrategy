# Alcance vigente

La versión informativa estática es un antecedente. El alcance actual está en [Brújula MVP v1.5](BRUJULA-MVP-v1.5.md): presentación y captación registrada, Next.js con servidor, Neon, Drizzle y WhatsApp como comunicación humana.

V2, pagos, cuentas de clientes, agenda pública, Cloud API y Habitia quedan fuera. No eliminar operación para declarar terminado el sitio; registrar evidencia de [aceptación](acceptance.md).
