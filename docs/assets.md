# Recursos de marca

Los archivos de identidad aprobados se ubican en `apps/web/public/brand` y las imágenes optimizadas para publicar en `apps/web/public/optimized`.

Para cada recurso se debe registrar:

- Propietario o fuente.
- Autorización de publicación.
- Uso previsto.
- Texto alternativo cuando transmita información.
- Dimensiones y formato de salida.

No se almacenan en el repositorio fotografías RAW, originales de video ni documentos privados de aprobación.

## Recursos incorporados

- `apps/web/public/brand/day-strategy-symbol.svg`: copia exacta de `SVG/Logo Fondo Blanco.svg`, entregado por DAY Strategy. Isotipo metálico transparente, `viewBox 0 0 1254 1254`; uso en encabezado, portada y footer. El nombre visible proporciona la identificación accesible.
- `apps/web/app/icon.svg`: copia exacta de `SVG/Logo Fondo Negro.svg`, del mismo paquete oficial; favicon.

No se altera el diseño del isotipo ni se aplica un gradiente nuevo sobre él.
